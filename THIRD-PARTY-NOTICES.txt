SobaFM image: third-party notices

The SobaFM image carries most license texts in place. This file adds the
notices the image would otherwise lack. See docs/supply-chain.md in the SobaFM
repository for what the image contains and what publishing it would owe. That
record is a project record, not legal advice.

Where the other notices are:

- Debian packages: /usr/share/doc/<package>/copyright, with the common license
  texts in /usr/share/common-licenses/.
- Python packages: the licenses/ folder of each .dist-info folder under
  /app/.venv/lib/python3.14/site-packages/. That includes the libraries compiled
  into dave-py (libdave, mlspp, nanobind, nlohmann-json, OpenSSL), PyNaCl
  (libsodium) and aiohttp (llhttp).
- pip: /usr/local/lib/python3.14/site-packages/pip-26.2.1.dist-info/licenses/.
- CPython's own license: /usr/local/lib/python3.14/LICENSE.txt.
- SobaFM: sobafm-0.0.0.dist-info/licenses/LICENSE (MIT) in the same site-packages
  folder as the other Python packages.

------------------------------------------------------------------------

A Debian package that apt depends on. SobaFM does not run it.

KNOWN GAP. /usr/share/doc/sqv/copyright covers sqv itself. The binary also
